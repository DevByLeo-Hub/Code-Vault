# 🎂 Neon Birthday Cake Animation

Bem-vindo ao código do meu projeto de Aniversário Neon! 🎉
Este é um projeto de **Creative Coding** focado em criar uma experiência visual imersiva e romântica para desejar um feliz aniversário.

![Demonstração do Projeto](image_739d1e.jpg)

## 🚀 Sobre o Projeto
Uma animação interativa construída do zero, combinando manipulação de elementos HTML com animações em Canvas para o fundo estelar. O destaque fica para a sincronia perfeita da montagem do bolo e a digitação do texto final.

### ✨ Funcionalidades Principais
* **Animação em Etapas:** O prato, as camadas de pão de ló, o recheio rosa e a cobertura branca surgem em uma sequência temporal precisa.
* **Fundo de Partículas (Canvas):** Um sistema de partículas gerando corações e bolinhas flutuantes com variação de opacidade e movimento contínuo.
* **Efeito Neon:** Balões flutuantes em tons brilhantes utilizando propriedades avançadas de `box-shadow` no CSS.
* **Chama Realista:** A vela possui uma animação de "flicker" (cintilação) no CSS que altera a escala e o brilho intermitentemente.
* **Efeito de Digitação:** O texto "Happy Birthday my Love!" é revelado letra por letra usando JavaScript nativo após o término da animação do bolo.

## 🛠️ Tecnologias Utilizadas
* **HTML5, CSS3 e JavaScript Vanilla**
* **GSAP (GreenSock):** Biblioteca de animação utilizada para criar a linha do tempo.
