## 🚀 Sobre o Projeto

Um projeto interativo construído do zero, combinando manipulação de elementos HTML e CSS com animações em Canvas para o fundo dinâmico[cite: 1, 2, 3]. O destaque fica para a sincronia dos balões flutuantes, o buquê central e o sistema de fogos de artifício ativados pelo usuário[cite: 1, 2, 3].

## ✨ Funcionalidades Principais

* **Fundo Estelar (Canvas):** Um sistema gerando estrelas que brilham de forma aleatória e estrelas cadentes que cruzam a tela ocasionalmente[cite: 3].
* **Fogos de Artifício Interativos:** Ao clicar com o mouse ou tocar na tela (em dispositivos móveis), sequências de fogos de artifício são disparadas e explodem na posição do clique[cite: 3].
* **Balões Flutuantes:** Elementos que soletram "L 🤍 V E", estilizados com gradientes e sombras, flutuando em tempos diferentes usando `@keyframes` no CSS para criar um efeito natural[cite: 1, 2].
* **Efeito Glow e Tipografia:** Uso das fontes `Montserrat` e `Playfair Display` com um efeito de brilho neon dourado (`text-shadow`) no texto "SUNSHINE"[cite: 1, 2].
* **Buquê Pulsante:** A imagem central do buquê de girassóis possui uma animação contínua e suave de pulsação de escala[cite: 1].
* **Cursor Personalizado:** O cursor padrão do mouse é substituído por um emoji de girassol (🌻) em toda a página[cite: 1].

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo[cite: 2].
* **CSS3:** Estilização de layout, gradientes, sombras (`box-shadow`, `text-shadow`) e animações avançadas (`@keyframes`)[cite: 1].
* **JavaScript puro:** Manipulação do elemento Canvas e orientação a objetos (Classes) para criar a gravidade, fricção e o decaimento das partículas dos fogos de artifício[cite: 3].

## 📂 Estrutura de Arquivos

* `index.html` - A estrutura principal da página.
* `style.css` - Contém todas as regras de estilo e animações dos balões e textos.
* `script.js` - O motor por trás do céu estrelado e dos fogos de artifício.
* `GIRASSOL.png` - A imagem do buquê utilizada no projeto.
* `Girassol.png` - Imagem de demonstração do REAqDME.

## 🚀 Como Executar

1. Faça o download ou clone este repositório.
2. Certifique-se de que a imagem `GIRASSOL.png` está na mesma pasta dos arquivos de código.
3. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web moderno.
4. Clique na tela para soltar os fogos de artifício!
